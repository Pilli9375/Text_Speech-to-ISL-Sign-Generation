# SignBridge module

The complete setup, operation, restoration, attribution and troubleshooting guide is in `../README.md`.
The canonical dictionary is `data/signs.json`; the roadmap CSV is a generated export under `data/metadata/`.

See `docs/evaluation_report.md` for the A–G handover, `docs/pdf_requirements_checklist.md` for PDF compliance,
and `docs/reviewer_and_evaluation_guide.md` for actual human review and held-out benchmark collection.

Default mode sequences dictionary matches. The opt-in reviewed-construction mode supports only orders
actually registered by an ISL-fluent reviewer; its initial registry is empty. Neither mode is general grammatical translation.
