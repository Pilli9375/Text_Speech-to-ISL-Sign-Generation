# Documentation index

- `evaluation_report.md`: current A–G engineering handover.
- `pdf_requirements_checklist.md`: requirement statuses, equivalents, exceptions and outstanding work.
- `reviewer_and_evaluation_guide.md`: asset acceptance/rejection and corpus collection procedures.
- `completion_metrics.json`: fixed-target coverage and optional externally supplied benchmarks.
- `code_verification.json`: latest actual automated code-check results.
- `release_validation.json`: validation of a specific archive digest; excluded from the archive itself to avoid self-reference.
- `data/metadata/sign_dictionary.csv` (relative to module root): generated roadmap interface.
- `dataset_audit.md`, `asset_audit.json`, `asset_register.csv`, `vocabulary_inventory.csv`: dataset/media provenance.
- `review_worklist.csv`: generated snapshot for an actual ISL-fluent reviewer.
- `evaluation_report_v1.0.md`, `evaluation_report_v1.1.md`, `library_expansion_result.json`: historical evidence, not current counts.

Use the repository-root README for setup and operation.
