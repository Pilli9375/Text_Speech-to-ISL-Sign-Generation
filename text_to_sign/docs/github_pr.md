SignBridge adds a local text/speech-to-ISL dictionary prototype to this initially empty repository. Typed text or an editable local speech transcript becomes a phrase-first video queue with complete alphabet fallback, cancellation, playback recovery and source attribution.

The collection contains 492 word/phrase clips and 26 letters, restored from external sources rather than committed as binaries. All media passed decoding; every clip still requires actual semantic/ISL review. Approved mode excludes pending media. An opt-in finite sentence-order interface accepts only human-reviewed constructions; its registry is initially empty and does not provide general grammatical translation.

Includes canonical metadata export, approval/rejection tooling, fixed-denominator coverage, held-out corpus evaluators, browser quality instrumentation, startup scripts and handover documentation. Independent review, representative speech evaluation and broader device/browser checks remain recorded external dependencies.

Validation: 69 Python and 16 JavaScript tests pass locally; all 518 clips passed fresh full decoding. See the A–G evaluation report for measured performance and limitations. Remote Windows/Linux CI must pass before merging.
